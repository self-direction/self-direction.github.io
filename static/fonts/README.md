# Fonts

Self-hosted, Latin-subset WOFF2 builds of three SIL Open Font License fonts from
[google/fonts](https://github.com/google/fonts). The page makes no third-party font requests.

| File | Font | Axes kept |
|---|---|---|
| `newsreader-roman.woff2`, `newsreader-italic.woff2` | Newsreader (Production Type) | opsz 6–72, wght 400–700 |
| `instrument-sans.woff2` | Instrument Sans (Instrument) | wght 400–700 (wdth pinned to 100) |
| `jetbrains-mono.woff2` | JetBrains Mono (JetBrains) | wght 500–700 |

Licenses: `OFL-*.txt`.
