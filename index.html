Summary

When an agent fails, Self-Direction turns the failure into a small LoRA skill. The skill fixes the retry, joins a growing library, and is reused on related tasks later, while the base model stays frozen.

01 · The problem

Extra compute usually disappears with the episode

Modern agents can often correct a mistake and finish the task at hand, but the recovery is ephemeral: in a new session the agent is just as likely to make the same mistake again. As workflows grow longer, every extra step is another chance to slip, and rediscovering the same lesson over and over is costly and makes performance inconsistent. The goal is not only to fix the mistake now, but to keep the lesson so it is not repeated.

Why the usual fixes fall short

Retry or resample

Extra attempts recover the task now (+10.9 pp with pass@3 on GAIA), but the weights are untouched, so nothing carries over to the next session.

Keep lessons in context

Reflections and skill files stay outside the policy: they must be retrieved every time and compete for a finite context. On GAIA, the full learning history would take about 3.1M tokens, nearly 12 context windows; a compact Skills.md fits, but recovers fewer failures than in-weight lessons.

Write lessons into the weights

Full fine-tuning is expensive and can interfere with what the model already knows. Pooling every lesson into one LoRA also dilutes it: it recovers 16.7% of GAIA failures, against 27.7% with one adapter per failure.

Abstract

Abstract

Intelligent agents should learn from their mistakes so experience compounds into continuous improvement. Yet today's agents recover from a mistake only temporarily: in-context reflections are easily forgotten across sessions and compete for limited context, while full-parameter fine-tuning is expensive and can interfere with existing capabilities. We introduce Self-Direction, a mechanism for agents to learn from mistakes that combines the benefits of temporary retries in-context and policy updates. When an agent fails a task, it reflects on its own trajectory in order to extract a lesson and immediately distills it into a lightweight low-rank adapter. By keeping the original weights frozen, Self-Direction preserves existing capabilities while only training 0.02% additional parameters for each adapter. The agent then saves these adapters into a persistent skill library, automatically routing them to solve related problems later.

Experiments with open agents based on the Qwen-family across open-ended research (GAIA), tool-use workflows (Claw-Eval), and terminal tasks (Terminal-Bench 2.1) show our method improves overall success rates by 8.9 to 17.0 percentage points and performs competitively with frontier systems. We find Self-Direction avoids repeating mistakes across future encounters of a task, nearly doubling the reliability of an agent's corrections and enables transfer of learned skills with just a handful of adapters generalizing to dozens of new tasks without additional training. Ultimately, this self-directed repair transforms everyday mistakes into lasting, reusable capabilities.

02 · Method

One loop: fail, reflect, distill, retry, reuse

The base model is never modified. Each lesson becomes a small adapter in a skill library, and a router decides whether a new failure needs a new skill or can reuse one it already has. The animation at the top walks through both paths.

  1. 1

    Attempt

    The frozen base agent attempts the task with its tools. When a verifier flags a failure, the task, the failure reason and the full trajectory are kept.

    wrong answer · no final answer · step or tool budget
  2. 2

    Reflect

    The same model reviews its own trajectory with the verifier's feedback and writes practice examples that teach the missing procedure: how to plan, use tools, verify and stop. It never writes the answer itself.

    up to 24 instruction → response examples
  3. 3

    Distill

    The examples train a small LoRA adapter while the base model stays frozen. The adapter joins the skill library, tagged with the failure that produced it.

    rank 16 · A from SVD of W, frozen · only B trained
  4. 4

    Retry & reuse

    The agent retries with the selected adapter and falls back to the clean base model if needed. Later failures can retrieve a stored adapter instead of training a new one.

    similarity ≥ τ → reuse · adapter first, then base

03 · Results

What the loop buys an agent

Self-Direction repairs mistakes across research, tool-use, coding and browser tasks, keeps those repairs on later encounters, and grows its skill library without disturbing what the agent already knows. Its skills also transfer to unseen tasks. Main experiments use Qwen3.6-27B; the paper's appendix repeats the loop on Qwen3.8-27B and Qwen3.5-9B.

3.1Paper §4.1

Repairs mistakes across task types

Over three runs, Self-Direction raises mean success on Claw-Eval from 64.4% to 73.3% and on Terminal-Bench 2.1 from 51.7% to 65.5%; on GAIA the gain is 17.0 points. It beats in-context reflections and a Skills.md file, matches the base agent's pass@6 on GAIA with only 2.10 rollouts per task, and narrows the gap to frontier agents. MiniWoB++ browser tasks improve as well, from 42% to 54%.

3.2Paper §4.2

Learned skills prevent repeated mistakes

Across 185 prior mistakes, Self-Direction nearly doubles the fraction solved in all three encounters, from 9.7% to 18.9%, with both methods allowed up to two rollouts per encounter. Once it repairs a mistake, 76.9% of repairs still hold on a second encounter and 67.3% on a third, against 52.4% and 42.9% for base retrying. On Terminal-Bench 2.1 it lifts every run and raises pass³ from 34.8% to 57.3%.

3.3Paper §4.3

New skills without losing old ones

Every task first runs on the unchanged base model, and each skill is a separate frozen adapter, so learning cannot overwrite what the agent already knows. The router loads a stored adapter only when the new task is similar enough to the one it came from (cosine similarity ≥ τ). With one global τ = 0.55, a library holding every adapter from GAIA, Claw-Eval and Terminal-Bench 2.1 never sends a task to another benchmark's adapter. Sweeping τ from 0.2 to 0.6, task success holds for all but very permissive thresholds, below 0.30.

3.4Paper §4.4

Skills transfer to unseen tasks

In a shuffled stream of all 165 GAIA tasks that starts from an empty library, a library capped at three adapters (256 MB in total) raises task success from 36.4% to 52.7%. Skills learned on easier Level 1 GAIA tasks lift unseen Level 2 tasks from 40.7% to 51.2% (base pass@2: 43%), and three Claw-Eval operations adapters solve half of the failed workflow tasks, from 75.0% to 87.5%, without training on a single workflow task.

04 · What gets learned

Skills are procedures, not answers

Reflection is told to teach the process and never to copy the answer, so a stored adapter carries a procedure that later tasks can reuse, across topics, modalities, difficulty levels and task categories.

05 · Where it fits

Where the lesson is stored

The paper compares four ways to repair a mistake, which differ in where the lesson lives once the episode ends. Each card shows GAIA task success; the base agent alone scores 38.8%.

Not stored

Resampling

Spend extra test-time compute on independent samples from the unchanged model. Nothing is kept, even within the session.

49.7% GAIA, base pass@3

In the session's context

Reflect in-context

Put reflections or the failed trajectory into the prompt and retry. The lesson is forgotten once a new session starts.

45.5% GAIA

In a shared text file

Accumulate a Skills.md

Distill reflections across sessions into one markdown file loaded into context. It avoids context overflow but falls short of in-weight lessons.

53.3% GAIA

In the weights

Self-Direction

Distill each lesson into its own LoRA adapter, kept in a persistent, routable skill library. The base model stays frozen.

55.8% GAIA
