# Self-Direction · project page

Project page for **"Don't Forget What You Just Learned: Self-Directed Repair Makes Agent Skills Persist"**
(Yuval Kansal, Karen Ullrich, Polina Kirichenko, Ilia Kulikov, Niraj K. Jha, Mohammad Pezeshki, Mark Ibrahim).

Built on the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template)
(itself adapted from [Nerfies](https://nerfies.github.io)). The page is plain HTML/CSS/JS with no build step,
and it makes no third-party requests: fonts are self-hosted.

## Preview locally

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```

Opening `index.html` straight from disk mostly works. Browsers restrict a few things on `file://` (the font
preload hints log console warnings), so use the local server for an exact preview.

## Where things live

| What | File |
|---|---|
| Page content: title, authors, sections, BibTeX | `index.html` |
| Design tokens (colors, fonts) and layout | `static/css/index.css`, tokens at the top |
| Results figures, rendered from the paper PDF | `static/images/paper/`, regenerated by `tools/extract_paper_figures.py` |
| Results tables (paper Tables 1, 3, 7) and captions | `index.html`, Results section |
| Page behaviour: figure tabs, BibTeX copy, nav highlight, scroll reveal | `static/js/index.js` |
| Title animation (self-contained) | `static/animations/self-direction-loop/index.html` |
| Favicon and social card | `static/images/favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `social_preview.png` |
| Fonts (SIL OFL) | `static/fonts/`, see its README |

The palette comes from the method figure: navy ink, **blue = train a new adapter**, **green = reuse a stored
skill / Self-Direction**, and an amber highlight.

## Results section = the paper's Section 4

Each finding (3.1–3.4 on the page) mirrors one subsection of the paper's Section 4. It shows the paper's own figures and
tables behind tabs: Figures 1, 2, 4, 5, 10, 11 and 12, and Tables 1, 3 and 7. "What gets learned" uses Tables 14–15, and
"Where it fits" uses Section 3.1 and Figure 2. When the paper PDF changes, regenerate the figures and re-check the
numbers and captions in `index.html`:

```bash
uv run --with pymupdf python tools/extract_paper_figures.py path/to/paper.pdf
```

## Deploy on GitHub Pages

1. Create a GitHub repository and point this clone at it. `origin` still points at the template:
   `git remote set-url origin git@github.com:<you>/<repo>.git`
2. Commit everything, including the deleted template files (`git add -A`), and push. This clone's branch is
   `master`; you can rename it with `git branch -m master main` if you prefer.
3. In the repository, go to **Settings → Pages → Build and deployment → Deploy from a branch**, then choose the branch
   you pushed and `/ (root)`. `.nojekyll` is already present. The site appears at `https://<you>.github.io/<repo>/`.

## Swapping the title animation

The animation follows a small embed contract, shared by all ten variants in
`self_direction_animations/variants/` in the `self-directed-lora-learning` research repo: a single HTML file with
`?controls=0`, `?bg=transparent` and `?autoplay=0` parameters and a `window.SDAnim` seek API. To swap it, replace
`static/animations/self-direction-loop/index.html` with another variant's `index.html`.
